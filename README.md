 # Arduino Line Follower Robot

## 1. Project Overview

This project consists of an autonomous robot that follows a black line on a white surface using infrared (IR) sensors and an Arduino board.

The robot detects the line and automatically adjusts its movement to follow the correct path.

## 2. Objectives

- Learn the basics of Arduino programming.
- Understand how IR sensors work.
- Control DC motors using a motor driver.
- Develop a simple autonomous robotic system.

## 3. Components Used

- Arduino board
- 3 IR sensors (Left, Middle, Right)
- L298N motor driver
- DC motors
- Robot chassis
- Battery
- Connecting wires

## 4. Working Principle

The IR sensors detect the black line on the white surface.

The Arduino reads the sensor values and controls the motors through the L298N motor driver.

Based on the sensor readings, the robot moves forward, turns left, or turns right to follow the line.
